# red social saint seiya

Red social ficticia de los Caballeros del Zodiaco creada con HTML, CSS, Bootstrap y JavaScript. Permite publicar, dar like, comentar y cambiar de personaje en un entorno interactivo y responsivo

## Tech Stack

HTML5, CSS3, JavaScript and Bootstrap

## Getting Started

```bash
git clone https://github.com/MagdaIG/red-social-saint-seiya.git
cd red-social-saint-seiya
Open index.html in your browser
```
